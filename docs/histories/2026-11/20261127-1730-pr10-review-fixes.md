### 🛠 Changes Overview

**Scope:** `apps/chrome-extension`、`cmd/open-browser-use`、`skills/open-browser-use`

**Key Actions:**

- **key**：`Ctrl+H` 这类带大写字母的快捷键不再额外加 Shift；支持单独的 `+`；run plan 支持 `key ctrl+h`、`screenshot page.png` 位置参数。
- **paste**：页面 handler 已插入文本但未 `preventDefault` 时不再重复插入；目标无法获得焦点时报错而不是输入到别处。
- **host 发现**：默认路径（无 `--browser/--profile`）也重试；host 有响应但 profile 不匹配时立即失败；没有 socket 时只等约 4 秒；等待时间从 `--timeout` 中扣除。
- **tab 归属**：从用户 tab 打开的新 tab 只有在 agent 刚发送输入后才归入 session；`--new-window` session 拒绝 claim 用户窗口中的 tab。
- **click**：`openedTabIds` 只统计由该 tab 打开或进入 session 的 tab；`newTabMissing` 只针对 `_blank`（含 `<base target>`）；警告合并而不是覆盖。
- **无 debugger 回退**：`Runtime.evaluate` 异常（含 CSP EvalError）以 `exceptionDetails` 返回；只有 `awaitPromise` 时才等待 promise。
- **tab 状态**：`visibleToUser` 需要窗口聚焦，新增 `activeInWindow`；`detachTab` 清除 focus emulation 记录。

PR #10 合并前没有经过独立 review。补做 review 后发现的问题集中在边界情况：快捷键大小写、误判用户 tab、对不会自愈的错误做无意义重试、回退路径吞掉异常。这些修复让行为与文档一致。
